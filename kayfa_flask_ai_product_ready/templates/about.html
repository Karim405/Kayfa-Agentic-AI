Project Explanation

What does this project do?

Kayfa Agentic AI is a Flask web application powered by LangGraph and OpenAI. It works as a multi-agent learning planner.

1. Assessment Agent

Evaluates the student's current level, strengths, and knowledge gaps.

2. Content Agent

Selects the most suitable courses from a simulated Kayfa Academy catalog.

3. Planning Agent

Builds a week-by-week personalized learning plan with tasks and projects.

4. Progress Agent

Analyzes completed lessons and quiz scores, then recommends improvements.
